# 💫 About Me
I am a **Senior UI Engineer / Frontend Architect** with **9 years of experience** building scalable, high-performance enterprise web platforms. I specialize in translating complex data into lightning-fast, intuitive user experiences (sustaining **60FPS** rendering for high-frequency data streams). 

Having navigated the evolution of the modern web platform, my expertise spans core browser architecture, evaluating **CSR vs. Server-Side Rendering (SSR)** for SEO, designing scalable data layers (**REST & GraphQL**), and migrating monolithic state stores to **decoupled state architectures** (Zustand, React Query). Currently, I am bridging robust system design with **Generative AI** to architect real-time, intelligent enterprise interfaces.
